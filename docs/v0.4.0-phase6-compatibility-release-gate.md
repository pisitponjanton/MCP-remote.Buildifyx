## User experience and guidance change

Updated `docs/v0.4.0-user-guide.md` with a dedicated *ChatGPT image attachments and the Cloud import fallback* section:
1. Clearly states chat-attached or ChatGPT-generated pictures are **not automatically available** to Buildifyx MCP; there is no current tool accepting a host-provided file object.
2. Outlines optional authenticated same-account `create_image_upload` → browser upload (PNG/JPEG/WebP <=4 MiB) → `send_uploaded_image_to_agent` → RAM `artifactId` → `get_cached_image` → separate `save_cached_image`.
3. Explains separate local `imageRead=Allow` + `cacheManage=Allow` for inbound bytes, `imageSave` for the explicit new destination; no overwrite and no permission bypass. Imported RAM expiry is 5 minutes, distinct from the 24-hour local disk image cache.
4. Marks the real hosted fallback, actual ChatGPT file input and production integration **UNVERIFIED**, and provides stable error-code guidance instead of misleading promises.

This Phase's source-code behavior was not changed; the only change was a user-guide edit and this Phase 6 report.
