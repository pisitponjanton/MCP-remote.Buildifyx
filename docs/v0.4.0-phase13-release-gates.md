## Fixes applied during Phase 13

- **RL03: deterministic Playwright version.** Pin `playwright` to exact `1.56.1` in `package.json` and `package-lock.json`. The fresh, isolated npm tarball installation now resolves Playwright **1.56.1**, matching checkout tests. Previously `^1.56.1` allowed a newer untested 1.64.0 to install.
- **RL04: Node 20.9.0 image decoder compatibility.** `sharp@0.35.5` has an ESM entry that uses `import ... with {type:'json'}`, which Node 20.9.0 cannot parse. The Agent's lazy image loader now uses the dependency's supported CommonJS entry via `createRequire`, fixing the real `IMAGE_INVALID` failure on image reads and screenshots under Node 20.9.0. Image/cache/browser/media tests importing Sharp were also switched to the same compatible entry so they can execute on the minimum declared Node runtime.
- Added `scripts/release-validate-browser-tarball.js` to exercise an **installed npm tarball**, not source checkout modules. It checks the exact Playwright package version and Chromium executable, then performs `browser_open -> browser_snapshot -> browser_screenshot -> browser_close` against an isolated 127.0.0.1 fixture with an isolated Agent cache. A missing browser produces an explicit failure instead of a silent skip. No production credentials are accessed.
