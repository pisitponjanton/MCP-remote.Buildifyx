## Important integration fixes in Phase 9

- Cloud socket close now aborts **all in-flight tool calls**, not only media transfers, and closes its controlled browser sessions. Persistent profile data stays on the user device.
- Cloud tool/management responses are tied to the socket that received their request. Stale results/errors are never sent over a newly connected socket. Safe-send functions tolerate a closed/null socket.
- Browser Control shutdown waits for any asynchronous profile/session closure already underway due to policy revocation or disconnect. Runtime calls the real Browser Control teardown, avoiding temporary-directory cleanup races.
- Existing login/device-token storage, Agent Protocol v2 and Management Protocol v1 were **not migrated or changed**. Release compatibility checks must verify these invariants against real installed versions.

## How to run

- `npm run check`: parse/check all JavaScript.
- `npm test`: full Agent suite; when Remote Agent response limits prevent a combined run, execute **every** `test/**/*.test.js` across non-overlapping groups and record exact pass/fail totals.
- `node --test test/browser/phase9-integration.test.js test/browser/phase9-cloud.test.js test/media/phase9-integration.test.js`: Phase 9 tests alone.
- `npm audit --omit=dev` and `git diff --check`; check untracked files separately.
- Chromium is installed on the macOS test host. A host lacking Chromium skips browser tests, so a skipped test cannot be counted as platform pass.

**Phase 10–12 boundaries:** Package/browser-install documentation, production/release gates, historical npm binaries and final read-only diff review remain pending. No commit, push, npm publish or deploy is performed in this phase.
